# Guide d’utilisation — StageConnect

Ce guide explique comment utiliser la plateforme StageConnect, pas à pas.

## 1. Créer un compte
1. Cliquer sur « Créer un compte » en haut à droite.
2. Choisir son profil : **Étudiant** ou **Entreprise**.
3. Remplir le formulaire (email, mot de passe, informations de profil).
4. Valider : vous êtes connecté automatiquement.

## 2. Côté étudiant
### Compléter son profil
- Aller dans « Profil », ajouter sa photo, sa ville, ses compétences et son CV.

### Chercher et postuler à une offre
1. Aller dans « Offres ».
2. Utiliser les filtres (type de contrat, ville, secteur) ou la recherche.
3. Ouvrir une offre, cliquer sur « Postuler », ajouter une lettre de motivation.
4. Suivre ses candidatures dans « Candidatures ».

## 3. Côté entreprise
### Publier une offre
1. Aller dans « Mes offres » → « Publier une offre ».
2. Remplir le titre, la description, le type de contrat.

### Gérer les candidatures
- Dans « Candidatures », voir les profils, consulter les CV, changer le statut
  (Acceptée, Refusée, Entretien).

## 4. La messagerie
- Depuis une offre ou un profil, cliquer sur « Contacter » pour démarrer une conversation.
- Les messages non lus sont signalés par un badge.
